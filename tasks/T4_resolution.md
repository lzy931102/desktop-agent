# T4 分辨率变化测试

## 目标

验证 Agent 在不同分辨率/缩放环境下，感知和点击依然正确。

## 背景

之前的测试都在 1920×1080、100% 缩放下跑。
真实环境可能：
- 不同分辨率（1366×768、2560×1440）
- 不同缩放（125%、150%）
- 游戏窗口大小变化

T4 验证 Agent 在这些环境下是否稳定。

## 前置

- 先读 PROJECT_STATUS.md
- 先读 test_moving_target.py（T1），复用感知逻辑
- 先读 test_stability_e2e.py（T8），复用稳定测试框架

## 步骤

### 第一步：给游戏加窗口大小参数

修改 E:\agent_test\game.py：

1. 加 argparse 参数：
   --window-width（默认 800）
   --window-height（默认 600）
   --target-radius（已有）

2. 窗口创建时用这些参数：
   self.root.geometry(f"{width}x{height}")

3. 状态文件里加上窗口尺寸

### 第二步：写测试脚本

新建 F:\opencode-workspace\test_resolution_e2e.py

测试矩阵：

| 窗口宽 | 窗口高 | 靶子半径 | 速度 |
|---|---|---|---|
| 800 | 600 | 30 | 0 |
| 1280 | 720 | 30 | 0 |
| 1920 | 1080 | 30 | 0 |
| 800 | 600 | 15 | 0 |
| 1280 | 720 | 15 | 0 |
| 1920 | 1080 | 15 | 0 |

每个组合跑 1 局，记录：
- 通关与否
- 总耗时
- 命中率
- 平均偏移（px）
- 是否有感知失败

### 第三步：验证点

对每个分辨率：
1. 窗口能创建
2. 靶子能被感知到（mss + OpenCV）
3. 点击坐标正确（点击后命中）
4. 感知坐标和真实坐标一致（可选，读状态文件对比）
5. 通关

### 第四步：跑测试

cd /d F:\opencode-workspace

python -u test_resolution_e2e.py

### 第五步：验收标准

- 6 个组合全部通关
- 命中率 > 90%
- 无感知失败
- 平均偏移 < 20px
