# T8 连续10局稳定性测试

## 目标

让 Agent 连续玩 10 局靶子游戏，验证长时间运行的稳定性。

## 前置

- 安装依赖：psutil
- 游戏脚本：E:\agent_test\game.py
- 测试脚本：F:\opencode-workspace\test_stability_e2e.py（从 D:\文档\Default Project\ 恢复）

## 步骤

### 第一步：循环 10 局

1. subprocess.Popen 启动靶子游戏
2. 等窗口出现（最多 5 秒）
3. Agent 玩一局，直到 Score: 10/10
4. 记录：本局耗时、点击数、命中率、内存占用（psutil RSS）
5. 关闭游戏窗口
6. 等待 1 秒

### 第二步：输出统计报告

- 总成功率
- 平均耗时
- 耗时标准差
- 内存增长（第10局 - 第1局）
- 是否有卡死/崩溃

### 第三步：运行

```bash
cd /d F:\opencode-workspace
set PYTHONUTF8=1
python -u test_stability_e2e.py
```

## 验收标准

- 10/10 通关
- 每局耗时标准差 < 平均值的 20%
- 内存增长 < 50MB
- 无卡死，无崩溃

- 循环 10 局：subprocess.Popen 启动游戏 → Agent 玩一局 → 关闭 → 间隔 1s

- 统计指标：总成功率、平均耗时、耗时标准差、内存增长
