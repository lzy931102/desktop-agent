# T6 计算器 E2E 测试

## 目标

验证 Agent 能打开计算器、执行两次运算（123×456=56088, 999+1=1000），通过 OCR 验证结果。

## 前置

- 安装依赖：pyautogui, opencv-python, pytesseract, DesktopAgent
- 系统自带 calc.exe
- 测试脚本：F:\opencode-workspace\test_calculator_e2e.py

## 步骤

### 第一步：打开计算器

- subprocess.Popen(["calc.exe"])
- 查找窗口：窗口尺寸 200-600 x 300-800 的可见窗口
- 按 C 清除状态

### 第二步：计算 123×456

- 按钮序列：1 → 2 → 3 → * → 4 → 5 → 6 → =
- OCR 读取显示区域，验证结果 == "56088"

### 第三步：清除

- 按 C 清除

### 第四步：计算 999+1

- 按钮序列：9 → 9 → 9 → + → 1 → =
- OCR 读取显示区域，验证结果 == "1000"

### 第五步：关闭

- PostMessageW(WM_CLOSE) 关闭计算器

### 第六步：运行测试

```bash
cd /d F:\opencode-workspace
set PYTHONUTF8=1
python -u test_calculator_e2e.py
```

### 第七步：验收标准

- 5 个步骤全部 PASS
- 123×456 OCR 结果 == "56088"
- 999+1 OCR 结果 == "1000"
- 失败自动重试（最多 3 次），重试时先按 C 清除

## 实际测试结果

**状态：已实现**

5/5 步骤全部 PASS，总耗时 10.6s。

- 123×456 = 56088（OCR 验证通过，重试2次）
- 999+1 = 1000（OCR 验证通过）

步骤明细：
- 打开计算器：3198ms
- 计算 123×456：3086ms（重试2次）
- 清除：886ms
- 计算 999+1：2561ms
- 关闭：830ms

## 关键实现要点

- 按钮坐标计算：基于窗口尺寸的比例定位（COL=[0.18,0.40,0.62,0.84]，ROW 各按钮不同）
- OCR 流程：截取显示区域 → 灰度 → 二值化 → 3x 放大 → pytesseract 识别
- 显示区域：窗口高度的 top 28%，取下半部分
- 字符白名单：0123456789.,-
- 失败重试策略：重试前自动清除计算器状态
