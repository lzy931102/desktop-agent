# T2 多靶子决策测试

## 目标

验证 Agent 能区分红色和蓝色靶子，只点红色，误点蓝色扣分。

## 前置

- 安装依赖：mss, opencv-python, numpy
- 游戏脚本：E:\agent_test\game.py，支持 --multi-target 参数
- 测试脚本：F:\opencode-workspace\test_multi_target_e2e.py

## 步骤

### 第一步：色彩检测

红色检测（双 HSV 范围）：
- 范围1：H=0-10, S=100-255, V=100-255
- 范围2：H=170-180, S=100-255, V=100-255

蓝色检测：
- 范围：H=100-130, S=100-255, V=100-255

### 第二步：决策逻辑

1. 每帧截屏，分离红色和蓝色靶子
2. 筛选条件：面积 > 300，圆形度 > 0.3
3. 选择最大红色靶子点击
4. 完全忽略蓝色靶子

### 第三步：运行测试

```bash
cd /d F:\opencode-workspace
set PYTHONUTF8=1
python -u test_multi_target_e2e.py
```

测试配置：3 局，每局最多 100 次点击，超时 30s。

### 第四步：验收标准

- 3 局全部通关（score ≥ 10）
- 误点蓝靶次数 = 0
- 平均命中率 > 90%
- 平均每局耗时 < 15s

## 关键实现要点

- FastIO 类：mss 截屏 + ctypes 点击，窗口坐标映射

- 游戏启动参数：--multi-target 启用多靶模式
