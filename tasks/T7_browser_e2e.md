# T7 浏览器 E2E 测试

## 目标

验证 Agent 能操控浏览器完成网页搜索任务（打开浏览器 → 输入搜索词 → 执行搜索 → 验证结果页加载）。

## 前置

- 系统已安装浏览器（Chrome / Edge）
- Agent 具备浏览器操控能力（pyautogui 键鼠操作）
- 测试脚本：F:\opencode-workspace\test_browser_e2e.py（从 D:\文档\Default Project\ 恢复）

## 步骤

### 第一步：打开浏览器

- 启动浏览器进程或激活已有窗口
- 等待窗口就绪

### 第二步：导航到搜索引擎

- 地址栏输入搜索引擎 URL
- Enter 导航

### 第三步：输入搜索词

- 聚焦搜索框
- 输入测试搜索词
- Enter 执行搜索

### 第四步：验证结果

- 等待搜索结果页加载
- 验证结果元素存在
- 记录耗时

### 第五步：关闭浏览器

- Alt+F4 或进程关闭

## 验收标准

- 浏览器能正常打开并导航
- 搜索词能正确输入
- 搜索结果页能成功加载
- 全流程无报错
