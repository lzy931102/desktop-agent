# 插件开发指南

> 插件系统与内置工具是两套东西：内置工具（click/type_text/...）随 exe 发布，插件是用户放进插件目录的 .py 文件。插件是任意可执行代码，只应安装可信来源的插件。

## 快速开始

1. **打开插件目录**：GUI 左侧栏底部点击"🔌 插件"按钮，然后点"📂 打开插件目录"。
2. **写插件**：在插件目录里新建一个 `.py` 文件，按下面的骨架写。
3. **刷新**：在插件面板点"🔄 刷新"，插件就会加载。
4. **启用/停用**：在插件列表里每个插件右侧有开关，停用后对 LLM 完全不可见。

## 插件骨架

```python
"""插件显示名：2~30 个字"""
NAME = "我的插件"
VERSION = "1.0.0"
DESCRIPTION = "一句话描述插件功能（插件面板展示）"

def tool_x(args):
    """工具实现，返回给 LLM 的字符串"""
    return "执行结果"

def get_tools():
    """返回工具定义列表"""
    return [{
        "name": "tool_x",                     # 工具名：小写字母开头，只能含 [a-z0-9_]，2~64 位
        "description": "给 LLM 看的工具说明（进工具 schema）",
        "parameters": {                      # JSON Schema，完整写法 {"type": "object", "properties": {...}}
            "type": "object",
            "properties": {
                "city": {"type": "string", "description": "城市名"},
            },
            "required": ["city"],
        },
        "run": tool_x,                       # 实现函数（可导入其他模块）
        "prompt_hint": "tool_x(city): 工具说明（进 system prompt）",
        "default_risk": "none",              # "none" | "medium" | "high"，缺省 medium
    }]
```

## 字段说明

| 字段 | 必填 | 类型 | 说明 |
|------|------|------|------|
| `NAME` | 是 | str | 插件显示名，2~30 个字 |
| `VERSION` | 否 | str | 版本号，如 "1.0.0"（面板展示） |
| `DESCRIPTION` | 否 | str | 一句话描述（面板展示） |
| `get_tools()` | 是 | list[dict] | 返回工具定义列表 |
| `name` | 是 | str | 工具名：小写字母开头，只能含小写字母/数字/下划线，2~64 位 |
| `description` | 是 | str | 给 AI 看的工具说明（进工具 schema） |
| `parameters` | 是 | dict | JSON Schema，完整写法 `{"type": "object", "properties": {...}}` |
| `run(args)` | 是 | Callable | 实现，返回给 LLM 的字符串；抛异常由执行层兜底成"错误: ..." |
| `prompt_hint` | 否 | str | 进 system prompt 的一行用法说明；缺省由 `name + description` 生成 |
| `default_risk` | 否 | str | "none" \| "medium" \| "high"，缺省 medium |

## 参数 Schema 写法

### 完整写法（推荐）

```python
"parameters": {
    "type": "object",
    "properties": {
        "city": {"type": "string", "description": "城市名"},
        "count": {"type": "integer", "description": "返回数量", "default": 1},
    },
    "required": ["city"],
}
```

### 简写（自动补全）

```python
"parameters": {
    "city": {"type": "string", "description": "城市名"},
    "count": {"type": "integer", "default": 1},
}
```

加载器会自动补成 `{"type": "object", "properties": {...}}`。

## 风险级说明

| 级别 | 行为 | 适用场景 |
|------|------|----------|
| `none` | 不拦截，不记录审计 | 只读操作（如查询天气、获取状态） |
| `medium` | 记录审计 + 界面提示，不拦截 | 有副作用但非破坏性（如发送消息、保存文件） |
| `high` | 高危操作，必须经过审批确认 | 删除、关闭窗口、修改系统设置 |

**默认是 `medium`**，fail-closed 设计：作者忘写风险级别时宁可多确认一次，也不放过危险操作。

## 示例插件

在插件面板点"✨ 生成示例插件"会自动生成一个示例（`示例插件-天气查询.py`）。示例返回演示数据，真实插件按这个骨架改即可：

```python
NAME = "天气查询"
VERSION = "1.0.0"
DESCRIPTION = "查询城市今天的天气（示例插件，返回演示数据）"

_FAKE_WEATHER = {
    "北京": ("晴", 26), "上海": ("多云", 29), "广州": ("雷阵雨", 31),
    "深圳": ("晴", 32), "杭州": ("小雨", 24),
}

def query_weather(args):
    city = str(args.get("city", "")).strip() or "北京"
    sky, temp = _FAKE_WEATHER.get(city, ("暂无演示数据（只有北上广深杭）", "--"))
    return f"{city}：{sky}，{temp}℃（演示数据）"

def get_tools():
    return [{
        "name": "query_weather",
        "description": "查询城市今天的天气",
        "parameters": {
            "type": "object",
            "properties": {"city": {"type": "string", "description": "城市名"}},
            "required": ["city"],
        },
        "run": query_weather,
        "prompt_hint": "query_weather(city): 查询城市今天的天气（演示数据）",
        "default_risk": "none",
    }]
```

## 常见问题

### 插件加载失败怎么办？

1. 打开插件目录，检查文件名是否以 `.py` 结尾。
2. 点面板里的"刷新"，看错误信息。
3. 常见错误：
   - `NAME` / `get_tools()` 缺失或格式不对
   - 工具名与内置工具或其他插件重名
   - 参数 schema 格式不对

### 插件停用后还能被调用吗？

不能。停用的插件不加载、不执行任何代码，对 LLM 完全不可见。停用只影响当前会话，下次启动生效。

### 插件可以调用其他模块吗？

可以。插件是完整 Python 模块，可以 import 第三方库或项目里的模块，但**不要在插件里做敏感操作**（如删除文件、修改系统设置），插件是任意可执行代码。

### 插件可以访问 Settings 吗？

可以，通过 `from core.settings import Settings` 读取，但插件是纯代码，不应该做持久化写操作。
