# 技能包指南（技能 / 专家 / 连接器）

> 插件中心在界面左下角「🔌 插件」按钮里。三类东西一句话说清：
>
> - **技能**：教 AI 做事的说明书（纯文本，不执行代码）
> - **专家**：给 AI 换个角色，改变它说话的方式和侧重
> - **连接器**：给 AI 接上外部工具的 .py 插件（见[插件开发指南](./插件开发指南.md)）

## 快速开始（不用写任何代码）

1. 点界面左下角「🔌 插件」→ 打开插件中心（三个标签页：技能 / 专家 / 连接器）
2. 点「✨ 生成示例」→ 立刻得到一个能用的示例包，照着看它长什么样
3. 每个包右侧有开关：**开**＝对下一个任务生效；**关**＝完全不注入
4. 「📂 打开技能目录」→ 技能包都放在这里（`%LOCALAPPDATA%\DesktopAgent\skills`）

## 技能包长什么样

一个技能包 = 技能目录下的**一个文件夹**，里面有**一个 SKILL.md**：

```
skills/
  会议纪要助手/          ← 文件夹名随便起（别用中文以外的怪符号）
    SKILL.md            ← 必须叫这个名字
```

SKILL.md 的写法（--- 里面是档案，--- 后面是给 AI 的指南）：

```markdown
---
name: 会议纪要助手
version: 1.0.0
type: skill
description: 教 AI 把看到的屏幕内容整理成清楚的会议纪要
triggers: 会议纪要, 整理要点
---

整理会议纪要时，按这个格式输出：
1. 标题：日期 + 会议主题
2. 要点：一条一行，每条不超过 30 字
3. 待办：谁、做什么、什么时候完成
```

### 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `name` | 是 | 显示名，2~30 个字 |
| `type` | 否 | `skill`＝技能（默认）；`expert`＝专家 |
| `description` | 是 | 一句话描述干什么用（面板上显示） |
| `version` | 否 | 版本号，如 1.0.0 |
| `triggers` | 否 | 什么时候适用，逗号分隔（面板上显示「什么时候用」） |
| 正文 | 建议 | 给 AI 的具体指南。**启用后整段注入提示词，建议 50 行以内**，超过 2500 字会截断 |

技能和专家用的是同一套格式，只有 `type` 不同：

- `type: skill` → 指南注入后，AI 做对应的事时按它执行
- `type: expert` → 角色设定注入后，**优先于默认人设**（说话方式、语气、侧重都按它来）

## 怎么装新的技能包

三种方式，都不用重启：

1. **手动放**：把技能包文件夹直接拷进技能目录，点「🔄 刷新」
2. **界面安装**：插件中心 → 对应标签页 → 「📁 从文件夹安装」（选文件夹）或「🔗 从网址安装」（粘贴 .zip 或 .md 的网址）
3. **让 AI 自己装**：任务里直接说——

   > 这是技能包的网址 https://example.com/打包.zip，帮我装上

   AI 会调用 `install_skill` 工具安装，装完把指南内容带回当次任务立刻使用。

### 安装规则（说人话）

- **同名＝更新**：装一个和已装包同名的包，会原地更新它（文件夹和开关状态不变），不会变成两个
- **坏包不收**：格式不对的包会被拒绝安装，错误信息直接告诉你怎么改
- **删错了不怕**：面板上点 🗑 删除（有确认弹窗），删掉的只是那一个文件夹

## 安全说明

- 技能包是**纯文本**（SKILL.md），不执行任何代码；连接器（.py 插件）才会执行代码，两者是分开的
- 从网址安装只认 `.zip` 和 `.md`，解压时拒绝路径穿越（zip-slip），内容超 10MB 拒收
- `install_skill` 属于 medium 风险操作：不拦你，但会记审计日志并在界面提示
- **只装可信来源的包**——说明书本身无害，但一份别有用心的「指南」可以让 AI 做出糟糕的事（比如让你输入密码）

## 常见问题

**技能包停用后还在吗？**
在。开关只是「这个包的指南不注入提示词」，文件还在技能目录里，随时能再开。

**AI 能自己写技能包吗？**
能。它可以用 `install_skill` 装（用户提供来源时）。也可以你自己照着示例包的格式写——就是普通文本文件，记事本就能改。

**专家可以同时开几个？**
可以，多个专家的设定会同时注入。没有冲突时没问题；两个专家要求相反时 AI 会犯难，挑着开就好。

**技能和连接器怎么选？**
想让 AI「知道怎么做某类事」→ 技能；想让 AI「换个脾气/角色」→ 专家；想让 AI「能操作一个新工具」（查天气、发消息）→ 连接器。
