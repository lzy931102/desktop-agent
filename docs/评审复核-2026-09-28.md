### 3.1 P0（2 条，建议最优先）

**P0-1　`.gitignore` 仍吃掉 `__init__.py`，且比 09-26 更危险**

```
$ git check-ignore -v plugin_system/__init__.py core/__init__.py
.gitignore:26:_*.py	plugin_system/__init__.py      ← 仍命中
.gitignore:26:_*.py	core/__init__.py               ← 仍命中

$ git ls-files plugin_system/
plugin_system/contract.py
plugin_system/manager.py
plugin_system/sample.py          ← 没有 __init__.py

$ git ls-files | grep __init__
（空）                            ← 仓库里一个都没有
```

**为什么现在更危险**：插件系统**已经接入主链路**（`agent_loop.py:43` `from plugin_system import PluginManager`）。
虽然 `:44-45` 有 `except → PluginManager = None` 兜底、不会崩，但**别人 clone 下来插件功能会静默消失**
（不报错、只是"插件怎么不生效"），比直接 ImportError 更难查。

修法（一分钟）：
```bash
# .gitignore 第 26 行 `_*.py` 之后补一行（顺序不能反）
!**/__init__.py
git check-ignore -v plugin_system/__init__.py   # 应无输出
git add -f plugin_system/__init__.py core/__init__.py
```

**P0-4　插件降级 medium 仍污染界面与审计**

`agent_loop.py:1158-1159` 照旧：

if self.auditor:
